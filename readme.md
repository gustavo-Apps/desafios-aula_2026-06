Objetivo: 
Desenvolver uma aplicação de gerenciamento de tarefas e demandas. 
Funcionalidades esperadas: 
* Cadastro de tarefas 
* Edição e exclusão de tarefas 
* Marcação de status (pendente, em andamento e concluído) 
* Organização por prioridade 
* Filtro de tarefas 
* Interface simples e intuitiva 
Diferenciais: 
* Login de usuário 
* Responsividade 
* Dark mode 
* Notificações
